## Update to 0.5.0

1. Close the old desktop app and any old connection/settings tabs.
2. Open Chrome/Edge Extensions and reload **Gaming Companion Bridge**. Confirm version **0.5.0**.
3. Run `start_stable_core.bat`.
4. Open your ChatGPT conversation(s) in the browser with the extension installed.
5. In the desktop app, click **Select ChatGPT Window**. Select a conversation and click **Connect**.

No pairing-file import, website setup, or connection page is needed. The extension reads a private local configuration generated by the desktop app automatically.

## Daily use

Open the desktop app and ChatGPT. The last selected conversation reconnects automatically when available.
To use another conversation or browser window for a different game, click **Select ChatGPT Window** again.
The picker shows the browser/window number, conversation title, and URL. The list updates automatically.
Screenshots cannot switch targets while a screenshot task is active.
Keep the selected conversation's draft empty. F8 / Xbox Share sends a 960 x 540 screenshot.
The flow is: paste one screenshot, confirm that image upload completes, and trigger its page Send control in the background.
No tab/window activation or system keyboard event is used. The selected composer's enabled Send control is invoked once through the DOM. Voice Mode is not closed.
The app then displays **UPLOAD COMPLETE â€” ENTER PRESSED** and releases the task immediately.
It does not inspect chat history or claim server-side message delivery is confirmed. Voice Mode is not automatically closed.

The entire application interface and extension diagnostics use English. Conversation titles remain as named by the user.

## Troubleshooting

If no tabs are listed, check that ChatGPT is open in the browser profile with **Gaming Companion Bridge 0.5.0** enabled.
After updating the extension, restart the desktop app. No file import is required.
The browser may display a debugger banner; the extension uses it to observe upload completion and press Enter in the exact editor.
Do not open DevTools for the selected conversation during a screenshot task.
Browser startup or sleeping may delay initial discovery; the picker automatically refreshes.

ChatGPT's private upload flow and DOM can change. The adapter requires the screenshot's matching file creation,
successful signed PUT upload. No additional `/uploaded` commit endpoint is required. Unknown flows fail without pressing Enter.
Timeouts only abort tasks; they never authorize sending. Ambiguous submissions are not retried automatically.
Actual live-browser compatibility still requires verification on the user's ChatGPT page.

Pairing is stored privately in `browser_bridge_pairing.json` and `browser_extension/local_pairing.json`.
The selected target is stored in `browser_target.json`. Do not share pairing files.
The HTTP service listens only on `127.0.0.1:8765` and requires its pairing token.
An optional English diagnostics page remains bundled; all connection choices are made in the desktop app.
